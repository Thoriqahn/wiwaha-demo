# Aset tema "Contoh Aset" (referensi standar aset)

Contoh susunan berkas berstandar aset (docs/standar-aset-tema.md): kanvas adegan 1080 × 3120
(kamera turun), pintu pembuka 1080 × 1920 menempel di layar, akhiran `__base`, `__fixed`,
`__tint` (SVG ber-`data-token`), `__mask` (PNG putih beralfa), `__fx` (glow 600 × 600, diberi
`kotak` di manifest). Gambar dibuat skrip, bukan ilustrasi final.

Setelah menambah/mengganti berkas: `pnpm tema:impor contoh-aset` → `pnpm tema:cek contoh-aset`.
