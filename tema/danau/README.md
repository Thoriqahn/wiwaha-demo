# Aset tema "Danau"

Letakkan berkas berstandar aset di folder ini (base/fixed raster, tint SVG ber-`data-token`,
mask PNG monokrom, fx glow/partikel). Kanvas adegan sama untuk semua berkas satu komponen.
Nama berkas: `danau__<komponen>[__<bagian>]__<base|fixed|tint|mask|fx>.<ext>`.
Spesifikasi lengkap: docs/standar-aset-tema.md.

Setelah menaruh berkas: `pnpm tema:impor danau` → `pnpm tema:cek danau` → `/contoh/danau`.
